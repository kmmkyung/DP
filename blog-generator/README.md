# 블로그 원고 생성기

우리가 제작한 홈페이지 주소를 넣으면 아래 두 가지를 만들어 줍니다.

1. **네이버 블로그 홍보 원고**: 기존 제작후기 글(예: [대혜건축 제작후기](https://m.blog.naver.com/PostView.naver?blogId=designpixel_&logNo=224371183856&navType=by))과 같은 흐름으로 작성됩니다.
2. **PC 화면 캡처(이미지 원고)**: 메뉴별로 첫 화면(1920×1080)과 전체 페이지를 캡처합니다.

외부 AI API는 쓰지 않습니다. 사이트에서 뽑은 정보를 정해진 문장 틀에 끼워 넣는 방식이라 비용이 들지 않습니다.

---

## 기획자용: 사용 방법

### 처음 한 번만: Node.js 설치
1. https://nodejs.org 에서 **LTS 버전**을 내려받아 설치합니다.
2. 이미 설치되어 있다면 이 단계는 넘어갑니다.

### 실행
| OS | 실행 방법 |
|---|---|
| Windows | `start-windows.bat` 더블클릭 |
| Mac | `start-mac.command` 더블클릭 (보안 경고가 뜨면 우클릭 → 열기) |

- 처음 실행할 때는 필요한 프로그램(Playwright, Chromium 브라우저)을 자동으로 설치합니다. 몇 분 걸립니다.
- 실행이 끝나면 브라우저에 `http://localhost:3000` 화면이 자동으로 열립니다.
- 검은 창(터미널)은 쓰는 동안 **닫지 마세요**. 닫으면 도구도 꺼집니다.

### 원고 만들기
1. 홈페이지 주소를 입력합니다. `http://`는 생략해도 됩니다.
2. 캡처할 페이지 수(메인 포함)를 고르고 **원고 만들기**를 누릅니다. 보통 1~2분 걸립니다.
3. 결과 화면에서 할 일
   - 원고 미리보기에서 **노란색 【 】 부분을 직접 채웁니다.** 업종, 핵심 강점처럼 사이트만 보고는 알 수 없는 내용입니다.
   - 오른쪽 패널의 **슬로건 후보, 페이지별 추출 문구**를 참고해 문장을 다듬습니다. 항목을 클릭하면 복사됩니다.
   - **원고 텍스트 복사**를 누르면 원고가 복사됩니다. 이미지 자리는 `[이미지 1] 01_MAIN.png`처럼 표시됩니다.
   - **전체 다운로드(ZIP)**를 누르면 캡처 이미지와 `원고.txt`를 한 번에 받습니다.
4. 결과는 `output/날짜-시간_사이트주소/` 폴더에도 저장됩니다.

### 파일 이름 규칙
- `01_MAIN.png`: 첫 화면(1920×1080). 블로그 본문용입니다.
- `01_MAIN_full.png`: 전체 페이지(최대 높이 15,000px). 길게 보여 줄 때 씁니다.

## 알려진 한계 (기획자 확인 필요)

- **메뉴 자동 인식:** `#gnb`, `nav`, `header` 안의 메뉴 목록을 찾습니다. 메뉴를 특이하게 만든 사이트는 메뉴를 못 찾을 수 있습니다. 그러면 메인 화면만 캡처합니다.
- **풀페이지 스크롤 사이트(fullPage.js 등):** 화면 전체가 한 장씩 넘어가는 사이트는 "전체 페이지" 캡처가 첫 화면과 같게 나옵니다.
- **팝업:** "오늘 하루 보지 않기" 같은 레이어 팝업은 자동으로 숨깁니다. 그 밖의 형태는 캡처에 찍힐 수 있습니다.
- **고객사명·슬로건은 추정값입니다.** 각각 og:site_name > 로고 alt > `<title>` 순서, 그리고 첫 화면에서 글자가 가장 큰 문구 기준입니다. 반드시 확인해 주세요.
- **포인트 컬러:** 화면에서 많이 쓰인 유채색을 자동으로 뽑은 값입니다. 브랜드 공식 컬러와 다를 수 있습니다.
- **로그인이 필요한 페이지**는 캡처하지 않습니다.

## 개발자용

### 구조
```
blog-generator/
├─ server.js            # 로컬 웹 서버 (Node 내장 http 모듈, 포트 3000)
├─ lib/
│  ├─ crawl.js          # Playwright로 사이트 열기 → 메뉴/슬로건/컬러/서체 추출 → 스크린샷
│  ├─ template.js       # 추출 정보 → 블로그 원고 (템플릿 치환). 문장/카테고리 수정은 여기서
│  └─ zip.js            # 의존성 없는 ZIP 생성 (무압축, UTF-8 파일명)
├─ public/index.html    # 기획자 화면
├─ start-windows.bat / start-mac.command
└─ output/              # 결과물 (git 제외)
```

### 명령어
```bash
npm run setup   # npm install + npx playwright install chromium
npm start       # http://localhost:3000
```

### 문장 틀 고치기
- 회사명은 `lib/template.js`의 `COMPANY` 상수에서 바꿉니다.
- 메뉴 이름에 따라 붙는 소제목과 설명은 `CATEGORIES` 배열에서 바꿉니다. 정규식으로 메뉴 이름을 매칭하며, 위에서부터 먼저 맞는 항목을 씁니다.
- 조사(은/는, 이/가, 을/를, 으로/로)는 `josa()` 함수가 받침을 보고 고릅니다. 마지막 글자가 영문이면 `은(는)`처럼 둘 다 표기합니다.

### 요구 사항
Playwright 1.56 공식 문서([intro.md – System requirements](https://github.com/microsoft/playwright/blob/v1.56.1/docs/src/intro-js.md#system-requirements)) 기준입니다.
- Node.js: 20.x, 22.x, 24.x 최신 버전
- Windows 11 이상 / macOS 14 이상
