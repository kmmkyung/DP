WCAG 2.2 국제 접근성 기준 근거 김민경
💬

이 자료가 필요한 이유. 디자인 시안에서 클릭이 되지 않는 텍스트나 이미지에 마우스를 올렸을 때 색상이 바뀌거나 밑줄이 생기는 경우가 있다. 사용자 입장에서는 당연히 "클릭할 수 있는 것"으로 인식하지만 실제로는 아무 동작도 하지 않는다. 이 문제는 국제 웹 접근성 기준(WCAG)에서도 명시적으로 다루는 사항으로, 기획 단계에서 디자인 검토 시 짚어줄 수 있어야 한다.

기준 01

링크의 시각적 구분

링크는 일반 텍스트와 시각적으로 명확하게 구분되어야 한다. 본문 내 텍스트 링크는 밑줄(underline) 등을 통해 링크임을 표현하고, Hover 상태에서는 색상·밑줄·굵기 등의 변화로 추가적인 피드백을 제공한다.

색상만으로 링크를 구분하는 것은 색각 이상 사용자가 링크임을 인지하지 못할 수 있어 접근성 측면에서 지양해야 한다.

주의할 점은, Hover나 Focus 상태에서만 밑줄 등 시각적 구분이 나타나는 경우도 실패로 간주된다는 것이다. 구분 표시는 Default 상태에서 이미 표현되어야 한다.

WCAG 2.2 · 1.4.1 Use of Color

기준 02

Interactive Affordance 일치

마우스를 올렸을 때 시각적으로 반응하는 요소는, 실제로 클릭했을 때 무언가 일어나야 한다. 링크도 버튼도 아닌 요소에 "클릭할 수 있어 보이는" hover 효과가 붙어 있으면, 사용자는 클릭을 시도하고 아무 반응이 없는 상황을 겪게 된다. 이를 False Affordance(잘못된 행동 유도)라고 한다.

아래 두 예시에 직접 마우스를 올려 차이를 확인해보자.

✓  올바른 예시
일반 텍스트입니다. 링크 텍스트입니다 →
✕  잘못된 예시 — hover해 보세요
일반 텍스트 (hover → 밑줄+색상) 장식용 텍스트 (hover → 색상) 보조 설명 텍스트 (hover → pointer)
⚠ 잘못된 예시의 텍스트는 hover 시 클릭 가능해 보이지만 실제 동작이 없습니다. 시각적 신호와 실제 동작이 불일치하면 False Affordance가 발생합니다.

기준 03

요소별 적용 기준

각 요소의 Default 상태, Hover 적용 여부, 커서 유형을 아래 기준에 따라 통일한다.

요소 Default 상태 Hover Cursor
Link <a> 밑줄 등 링크 구분 시각화 권장 pointer
Button 버튼 형태 명확히 표현 권장 pointer
Clickable Card 클릭 가능함을 시각적으로 표현 권장 pointer
Accordion / Toggle 조작 가능함을 표현 권장 pointer
일반 텍스트 일반 텍스트 상태 유지 지양 default
장식 요소 / 아이콘 장식 상태 유지 지양 default

디자인 시안에서 확인할 것

디자인 검토 회의나 시안 피드백 시 아래 항목을 기준으로 확인할 수 있다.

본문 안의 링크가 일반 텍스트와 시각적으로 구분되는가? (색상만으로 구분하는 경우 지적)
링크처럼 보이는 텍스트에 실제로 클릭 동작이 연결되어 있는가?
마우스를 올렸을 때(hover) 색상·밑줄·커서가 바뀌는 요소가 실제로 클릭 가능한가?
클릭되지 않는 일반 텍스트, 이미지, 장식 요소에 hover 효과가 붙어 있지 않은가?
링크의 밑줄이 hover했을 때만 나타나도록 설계되어 있지 않은가? (기본 상태에서 이미 구분되어야 함)

W3C · WCAG란?

W3C(World Wide Web Consortium)는 1994년 설립된 웹 기술 국제 표준화 기구다. HTML, CSS, SVG 등 웹 핵심 기술의 표준을 제정하며, 산하 조직인 WAI(Web Accessibility Initiative)가 접근성 관련 표준을 담당한다.

WCAG(Web Content Accessibility Guidelines)는 WAI가 발행하는 웹 접근성 지침으로, 전 세계 법적 접근성 요구사항의 기준으로 활용된다. 준수 수준은 세 단계로 나뉘며, 본 문서가 인용하는 1.4.1 Use of Color는 가장 기본적인 요건인 Level A에 해당한다. 현재 최신 버전은 WCAG 2.2(2023년 10월 공식 발행)이다.
